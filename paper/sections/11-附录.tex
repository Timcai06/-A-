\subsection*{A.1 数据口径}

本文真实价格数据只来自赛题附件，并经清洗后形成中文命名数据文件。短期拟合使用附件中 2026 年 3 月 3 日至 2026 年 5 月 5 日的冲突窗口；2017--2026 年完整价格序列仅用于历史同长度窗口、基准模型分布和事件极端性检验。EIA 周度 SPR、商业库存和原油产量数据、JODI 多国月度产量、库存、进出口、需求和炼厂数据、OPEC 全球供需平衡表、GPR 月度指数和 OVX 隐含波动率用于外部合理性校验，不反向替代附件真实价格。

\subsection*{A.2 综合机制递推模型伪代码}

为避免在附录中堆叠大量源代码，本文只列出主模型的核心计算逻辑。完整程序随项目文件保存，若提交系统要求源程序，可作为单独附件提供。

{\small
\begin{verbatim}
输入：
  附件布伦特价格序列 P_t
  供应中断 I、基础需求 D_0、短期弹性 epsilon_t
  SPR 释放 R_t、商业库存 B_t、绕道运输 Q_t
  恐慌强度 F_t、地缘风险权重 beta、调整速度 v

初始化：
  设定 P_hat_0 = P_0
  根据题面约束确定 I、SPR 上限、绕道能力和短期弹性范围

对冲突窗口内每一日 t = 1,2,...,T：
  1. 计算有效供应：
       S_t = S_0 - I + R_t + B_t + Q_t
  2. 计算有效需求：
       D_t = D_0 * (1 + 恐慌需求项 + 需求收缩项)
  3. 得到剩余缺口：
       G_t = max(D_t - S_t, 0)
  4. 构造目标价格：
       P_t^* = 基准价格
             + 物理缺口压力
             + 地缘风险溢价
             + 冲击不确定性溢价
             + 恐慌溢价
             - 缓冲确认折价
             - 预期修复折价
  5. 日度递推：
       P_hat_t = P_hat_{t-1}
               + v * (P_t^* - P_hat_{t-1})
               + gamma_F * (F_t - F_{t-1})
  6. 记录预测值、误差和各机制贡献

输出：
  短期拟合路径、误差指标、机制贡献、消融结果和长期情景初始状态
\end{verbatim}
}

\subsection*{A.4 稳健性检验补充}

\begin{itemize}[leftmargin=2em,itemsep=0.2em]
  \item 基准检验：与上一日价格、漂移随机游走和滚动 ARIMA 比较，防止模型只是复杂但无效的随机游走复制。
  \item 滞后检验：检查预测曲线是否简单滞后真实价格，避免“马后炮曲线”问题。
  \item 消融检验：逐项移除风险溢价、缓冲折价、预期修复等机制，验证各因素的边际贡献。
  \item 参数压力测试：扰动价格传导、风险权重和长期机制参数，检验结论是否依赖唯一一组参数。
  \item 外部校验：EIA 周度数据、JODI 多国月度石油数据、OPEC 全球供需平衡表、GPR 月度指数、OVX 隐含波动率和 2017--2026 历史同长度窗口用于验证数量级、风险定价和事件极端性。
\end{itemize}
