# 独立专家评审报告：霍尔木兹海峡封锁原油价格模型

**评审日期：** 2026-05-12
**评审人：** 模型诊断专家
**评审对象：** 总论文.tex、综合机制递推模型、三情景预测模型

---

## 一、总判断

**模型现状：** 一份工程量充足、防御意识强烈、但经济学根基存在结构性缺陷的竞赛论文。

论文作者显然意识到大量潜在质疑，并主动构建了防御体系（消融、压力测试、参数分类、滞后检验）。但防御措施堆砌再多，也掩盖不了一个核心问题：**整个模型缺乏一般均衡视角，导致供需基本面与价格输出之间出现严重撕裂。**

具体而言：短期模型（46天拟合）尚有可辩护空间，但长期外推（60-180天）建立在违背经济学常识的机制假设上，属于"数值拟合游戏"而非"机制解释模型"。

## 二、短期模型评价（46天冲突窗口）

### 2.1 优点承认

| 维度 | 评价 |
|------|------|
| 基准对比 | RMSE 3.44 vs 朴素基准4.47，确有改善 |
| 平移检验 | 原始位置误差最低，证明非滞后复制 |
| 机制消融 | SPR、风险溢价去除后误差显著恶化，有说服力 |
| 压力测试 | ±15%扰动下峰值区间合理，参数不过度敏感 |
| 论文写作 | 防御性叙事完整，图表规范 |

### 2.2 致命缺陷一：压力传导系数的"数字障眼法"

**核心质疑：你们嘴上用-0.05弹性，实际系统弹性已被偷偷改成-1.7。**

代码中`shortage_pressure`计算：
```python
shortage_pressure = (
    base_price
    * behavior.pressure_scale  # 0.029
    * (residual_gap / base_demand)
    / abs(elasticity)
)
```

**数学本质拆解：**

- 题面要求：$\Delta P/P \approx \frac{I/D_0}{|\varepsilon|}$，其中$\varepsilon = -0.05$
- 实际代码：再乘以`pressure_scale = 0.029`
- 真实效果：等效弹性变为$-0.05 / 0.029 \approx -1.72$

**这不是微调，这是一个数量级的改动。**

论文的叙事逻辑是："看，SPR+库存+绕道+需求收缩成功把油价从300多压到110美元区间。"但真相是：**如果真的执行1400-1800万桶/日的封锁且需求弹性只有-0.05，没有任何一个政策缓冲组合能把油价维持在110美元。真正把价格压下来的是代码里这个0.029系数。**

消融实验显示"去除SPR后RMSE从3.44升至5.86"——这只能证明SPR有边际贡献，但无法证明SPR是价格压在110美元的核心原因。更诚实的消融实验应该问：**"如果把pressure_scale改为1.0（即真实使用-0.05弹性），模型还能用SPR+库存解释110美元的价格吗？"** 答案是不能。

**建议修改：** 必须在论文中明确承认，`pressure_scale`的作用本质上是"期货市场对物理缺口的折价传导比例"，它不是题面弹性，而是对市场结构的行为假设。这个假设必须有外部文献支撑（如Kilian 2009关于期货市场的论述），否则就是"拿结论调参数"。

### 2.3 致命缺陷二：风险溢价的"无中生有"

代码中地缘风险溢价：
```python
blockade_risk_premium = (
    base_price
    * risk_weight  # 2.46
    * (interruption / base_demand)
    * (1 - exp(-day/7)) * exp(-0.004*day)
)
```

**两个致命问题：**

**问题A：符号方向反常识**

公式中$(1 - e^{-t/7})$表示风险溢价在前期快速累积。对于霍尔木兹海峡封锁这种预期事件，市场在封锁前（即$t=0$时）就已经开始定价。但模型中$SPR$释放有延迟（第3-14天才启动），意味着封锁真正造成物理缺口时，市场风险溢价已经处于高位平台——这在逻辑上是合理的。

**真正的问题**在于：这个风险溢价在180天的尺度上会逐渐衰减（因为乘了$e^{-0.004t}$），但你们同时用`uncertainty_floor`项补充了一个随时间**递增**的渐近溢价。两者叠加后的效果是：风险溢价在前期飙升后，维持在一个相对稳定的水平。

**问题B：数值来源不透明**

`risk_weight = 2.46`是怎么来的？消融实验显示"去风险溢价后RMSE飙升到30.69"——这只能证明它重要，但不能证明2.46这个具体数值合理。

如果把risk_weight设为1.0（即风险溢价减半），模型能否重新校准到相近误差？答案是肯定的。**2.46不是物理常数，而是一个在当前参数体系下的拟合值。**

**建议修改：** 必须明确区分两类风险溢价：
1. **可外部校准的部分**：如Caldara-Iacoviello GPR指数，可以用历史数据拟合系数
2. **纯行为假设的部分**：必须标注为"专家判断参数"，并做敏感性分析（±50%扰动）

### 2.4 缺陷三：多目标校准的"参数膨胀"

论文声称采用多目标校准：
```
L = RMSE + 0.20×|ΔPpeak| + 0.25×|ΔPfinal| + ...
```

**问题：目标函数权重本身就是隐藏的超参数。**

你们选了0.20、0.25这些数值，但没有回答：**如果把末日价格权重从0.25降到0.10，会不会得到一组完全不同的"最优参数"？**

更危险的是：**21个连续校准参数 vs 46个数据点**，自由度已经严重超标。1000组±15%压力测试只能证明"在这个目标函数下，参数不是唯一神奇的"，但不能证明"在这个目标函数下，任何参数组合都同样合理"。

**建议修改：** 加入参数等效性检验：固定部分参数（如所有物理层参数），只校准行为层参数，比较结果差异。

## 三、长期模型评价（60-180天情景预测）

### 3.1 致命缺陷四：供需撕裂的"600万桶过剩悖论"

这是整个模型最致命的问题，必须在论文中正面回应。

**情景复现（中性情景第180天）：**

| 变量 | 数值 | 来源 |
|------|------|------|
| 战前需求 | 10000万桶/日 | base.yml |
| 价格相对战前涨幅 | (104-75)/75 = 39% | 情景预测 |
| 长期需求弹性 | -0.25 | scenarios.yml |
| 有效需求 | $10000 \times (1.39)^{-0.25} \approx 8914$万桶/日 | 计算 |
| SPR释放 | 670万桶/日 | 固定上限 |
| 绕道运输 | 237万桶/日 | 固定上限 |
| 供应中断 | 1493万桶/日 | 中性设定 |
| **有效供给** | $10000 - 1493 + 670 + 237 = 9414$万桶/日 | 计算 |
| **剩余缺口** | $8914 - 9414 = -500$万桶/日（过剩！） | 计算 |

**数学事实：第180天，模型计算出的结果是每天过剩500万桶原油。但同时给出的价格是104美元/桶，比战前75美元高出39%。**

在任何一个基础经济学原理中，这不是均衡，这是崩溃前奏。

**论文的诡辩术：** 你们说"SPR自适应收缩"，但代码中的SPR释放是：
```python
spr_release = min(spr_max, ramp(day, delay, ...))  # 没有价格反馈
```

`ramp`函数是时间的确定性函数，与价格是否回落**完全无关**。当价格从110美元开始回落时，SPR仍在按每天670万桶的速度释放。这不是"自适应"，这是"死循环"。

**真正的市场逻辑应该是：**
- 当有效供给 > 有效需求时，供给方开始降价竞争
- 当价格跌破某个阈值时，IEA成员国停止释放SPR
- 当库存耗尽且价格足够高时，需求开始从替代能源回流

**你们模型的漏洞：** 没有任何一个机制负责"当供给过剩时，价格自动向战前回归"。所有的价格压制力量（缓冲确认折价、预期修复折价、不确定性溢价）都是外生给定的，不是内生决定的。

### 3.2 致命缺陷五："不确定性溢价"的反逻辑构造

代码中的不确定性溢价：
```python
uncertainty_premium = base_price * uncertainty_floor * (1 - exp(-day/18))
```

**数学本质：** 这是一个随时间递增并永远维持在最高点的函数。

| 时间点 | $(1-e^{-t/18})$值 | 贡献（base=75, floor=0.247） |
|--------|-------------------|-------------------------------|
| t=30天 | 0.811 | 15.0美元 |
| t=90天 | 0.993 | 18.4美元 |
| t=180天 | 0.9999 | 18.5美元 |

**经济学致命问题：**

1. **违背"新常态"原理**：真实市场中，一个持续半年的封锁事件会逐渐被市场消化，不确定性应该**衰减**，而不是维持在最高水平。

2. **违背"锚定效应"**：当市场已经看到SPR在释放、库存有缓冲、价格已经上升到110美元平台时，不确定性应该降低，而不是继续增加。

3. **与其他机制矛盾**：如果真的有"永不消退的不确定性溢价"，那么乐观情景和悲观情景的最终价格差距应该更大。但你们的蒙特卡洛显示第180天P5-P95只有91.67-108.31，差距只有约17美元——说明这个"永久不确定性溢价"对两条情景线的区分度几乎为零。

**建议修改：** 将不确定性溢价改为随时间**衰减**的形式，并在论文中论证：为什么霍尔木兹封锁的不确定性会在180天内维持在最高水平，而不是逐渐消退。

### 3.3 缺陷六：长期弹性插值的任意性

代码中：
```python
elasticity = interpolate_elasticity(day, horizon_days=60)
weight = day / horizon_days
elasticity = base_elasticity + (long_elasticity - base_elasticity) * weight
```

**问题：** 为什么用60天作为从短期弹性过渡到长期弹性的时间尺度？这个60天有外部依据吗？

如果把`horizon_days`改成30天或90天，模型结果会发生显著变化。但论文没有报告这个敏感性。

## 四、建模方法论层面的系统性缺陷

### 4.1 缺乏"可反驳性"设计

一篇好的建模论文，应该主动设计"如果我的假设是对的，那么X情况下模型应该输出Y；如果是错的，模型应该输出Z"。

当前模型的问题：**它对几乎所有关键假设都是"正着说"的**——

- "不确定性溢价递增" → 所以价格维持高位 ✓
- "SPR无限释放" → 所以物理缺口被填补 ✓
- "需求弹性低" → 所以价格对缺口敏感 ✓

但**没有设计反驳性检验**：
- 如果不确定性溢价应该**递减**呢？模型会崩溃吗？
- 如果SPR释放在价格超过100美元时就会减少呢？模型能处理吗？
- 如果真实市场存在"供给过剩时价格崩溃"机制呢？模型有吗？

**真正科学的模型应该是：如果上述任一假设被否定，模型能自然地调整到新的均衡，而不是需要人为添加新的"折价项"来硬拽价格。**

### 4.2 缺乏"模型一致性"检验

论文有"机制消融"检验，但没有"模型一致性"检验：

**问题A：短期模型和长期模型用的是同一套机制吗？**

短期模型有"恐慌衰减"，但长期模型里这个项去哪了？论文没有明确说明。

**问题B：长期模型中供应中断量固定为常数——但这违背"长期供给响应"假设**

scenarios.yml里设定供应中断量180天内不变。但如果真的封锁持续180天：
- 伊朗/俄罗斯是否会增产填补缺口？
- 页岩油是否会在120美元高价下大量涌入？
- OPEC剩余产能是否会释放？

论文承认了"供给恢复"可以作为扩展方向，但没有进入主模型。这是一个**主动放弃的机制缺口**，不应该被当成模型优点来炫耀。

### 4.3 缺乏"量纲一致性"检查

baseline.yml中：
```yaml
baseline_assumptions:
  pre_war_supply: 10000   # 万桶/日
  commercial_inventory: 58000  # 代码里写的是万桶
```

但论文表格里写的commercial_inventory是58000万桶 = 5.8亿桶。美国实际商业库存约10亿桶量级，中国SPR约3亿桶。**你们设定的库存量级是否符合全球实际储备水平？**

更重要的是：**如果把库存设定为真实全球水平（如30亿桶），模型的库存缓冲机制会有显著不同吗？** 论文没有做这个敏感性检查。

## 五、蒙特卡洛分析的评价

### 5.1 优点承认

- 2000次抽样，样本量充足
- 引入综合压力指数z，统一刻画多因素联动
- P05-P95区间表达比单点预测更诚实

### 5.2 致命缺陷：联合分布缺乏外部依据

蒙特卡洛的前提是：**参数联合分布来自可信的外部估计**。

你们的抽样设计：
```python
# 供应中断量随z增大而上浮
supply_interruption = interruption_base + z * (interruption_high - interruption_base)
```

**问题：这个z分布（z∈[0,1]的均匀分布）有外部依据吗？**

如果评委问："凭什么假设供应中断量和地缘风险权重是同步变动的？万一它们是负相关的呢？"

你们无法回答，因为**整个联合分布是模型自己设定的**，而不是从历史数据或专家估计中得出的。

**论文的诚实表述应该是：** "本文的蒙特卡洛情景树给出的是**模型设定下的条件概率**，不是历史频率意义上的真实市场风险概率。"

## 六、核心改进建议

### 6.1 必须修改的致命问题

| 优先级 | 问题 | 修改建议 |
|--------|------|----------|
| P0 | 供需撕裂悖论 | 在长期模型中加入"供给过剩→价格自动下跌"的内生机制，或明确承认模型缺乏此机制 |
| P0 | 不确定性溢价反逻辑 | 改为随时间衰减，或提供外部文献支撑"永久高不确定性"的假设 |
| P0 | pressure_scale来源 | 必须在论文中明确它是"行为假设参数"而非"题面弹性修正" |
| P1 | SPR无价格反馈 | 将SPR释放改为受价格/缺口触发的条件函数 |
| P1 | 长期弹性horizon_days | 改为外部可估计的参数，不作为隐含常数 |

### 6.2 建议加入的反驳性检验

| 检验 | 目的 |
|------|------|
| "如果不确定性衰减"情景 | 检验模型对不确定性假设的敏感程度 |
| "价格反馈SPR"机制 | 检验内生政策反馈能否减少外生参数 |
| "供给响应"敏感性 | 检验长期供给恢复对最终价格的影响 |
| "真实弹性校准" | 用历史油价数据重新估计需求弹性范围 |

## 七、最终评审结论

**论文可答辩的强项：**
- 短期模型（46天拟合）在防御性检验方面做得比较充分
- 多目标校准、多层消融、参数分类等工作量充足
- 论文写作规范，叙事逻辑清晰，图表质量高

**论文难以答辩的致命伤：**
- 长期模型的"600万桶过剩悖论"是结构性问题，无法靠调参解决
- "不确定性溢价递增"违背基础经济学原理，需要从机制上重构
- 蒙特卡洛概率是模型内生设定，缺乏外部校准依据
- 整个模型缺乏"价格→政策→供给→需求"的负反馈闭环

> "你们的长期模型预测第180天价格为98美元，但我看到此时模型计算出的供需基本面是每天过剩500万桶。请告诉我：这500万桶过剩为什么没有把价格压回战前水平？"
