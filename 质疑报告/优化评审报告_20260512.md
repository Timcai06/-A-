## 二、仍存在的关键问题

### 问题1：不确定性溢价的"数值暗雷"

**位置：** simulation.py:115-127

```python
shock_uncertainty = base_price * behavior.uncertainty_floor * 0.45 * buildup * shock_decay
#                    ↑ 基础值     ×0.45放大  ↑ 时间累积后衰减

regime_risk = base_price * behavior.uncertainty_floor * 0.90 * regime_share * confidence_decay
#              ↑ 基础值     ×0.90放大  ↑ 依赖未解决压力
```

**问题：** 0.45 和 0.90 的放大系数是什么意思？

- `uncertainty_floor = 0.247`
- 中性情景第180天的不确定性溢价 ≈ $75 \times 0.247 \times 0.90 \times 1.0 \times 0.4 \approx 6.64$ 美元

**核心问题：** 这两个放大系数（0.45、0.90）是从哪里来的？是：
- A. 从历史数据拟合出来的？
- B. 专家判断？
- C. 调参凑出来的？

如果选C，这就是上一轮"数字障眼法"的变体——**用放大系数维持价格，而不是基于机制**。

**建议：**
1. 论文必须明确说明这两个系数的来源（外部文献/历史校准/专家判断）
2. 做敏感性检查：把0.90改为0.50、0.30、0.10，观察第180天价格变化
3. 如果0.90不是外部可解释的，应将其归入"行为校准参数"类，明确标注为专家判断

### 问题2：oversupply_discount的1.35系数

**位置：** simulation.py:145

```python
excess_supply_discount = base_price * behavior.pressure_scale * 1.35 * (oversupply / base_demand) / elasticity
```

**问题：**
- 短期模型中 `pressure_scale = 0.029`
- 长期模型中把这个系数再乘以1.35 ≈ 0.039
- 等效弹性再次变为 $-0.05 / 0.039 \approx -1.28$

**核心问题与问题1相同：** 1.35这个系数有外部依据吗？还是为了"让供给过剩时价格下跌足够多"而凑出来的？

**如果改成0.5会发生什么？** 价格可能只从92美元跌到85美元，而不是维持得住。

### 问题3：neutral情景参数继承的不对称性

**位置：** parameters.py:100-112

```python
# 乐观情景：behavior参数全部×系数（0.82, 0.70, 1.08等）
optimistic = (
    base_assumptions + modify,
    replace(base_behavior, pressure_scale=base_behavior.pressure_scale * 0.82, ...)
)

# 中性情景：直接继承，不修改任何behavior参数
neutral = (
    replace(base_assumptions, ...),
    base_behavior,  # ← 直接使用校准参数，不做任何调整
)

# 悲观情景：behavior参数全部×系数（1.35）
pessimistic = (
    base_assumptions + modify,
    replace(base_behavior, pressure_scale=base_behavior.pressure_scale * 1.35, ...)
)
```

**问题：** 中性情景为什么不调整behavior参数，而乐观和悲观都要调整？

这会造成一个隐含假设：**中性情景代表"校准参数不变且封锁持续中性"**，但这实际上是在说"中性=最接近46天校准窗口的现实"。这两个假设是否等价，论文没有明确说明。

### 问题4：短期模型和长期模型的不确定性溢价不一致

**短期模型（dynamic_short_term.py:245）：**
```python
uncertainty_premium = base_price * behavior.uncertainty_floor * (1 - np.exp(-day_index / 18))
# 随时间递增的渐近线，无衰减
```

**长期模型（simulation.py:113-127）：**
```python
shock_uncertainty = base_price * behavior.uncertainty_floor * 0.45 * buildup * shock_decay
regime_risk = base_price * behavior.uncertainty_floor * 0.90 * regime_share * confidence_decay
# 两者都随时间衰减
```

**问题：**
1. 短期模型用的是"递增渐近线"，长期模型用的是"衰减结构"——两者机制不一致
2. 短期模型校准出来的 `uncertainty_floor` 是针对"递增"结构的，长期模型换成了"先增后减"结构后，这个参数还能直接用吗？

**这会导致一个风险：** 短期校准出来的最优参数，在长期模型中可能不再是最优，因为长期模型改变了不确定性溢价的函数形式。
