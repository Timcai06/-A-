# 数学建模 A 题：霍尔木兹海峡封锁对原油价格的影响

本项目用于完成浙江工商大学 2026 年大学生数学建模竞赛 A 题。当前主线已经收敛为一套可复算的综合机制递推模型，并生成最终论文 PDF/DOCX。

## 当前结论

本文解释的问题是：霍尔木兹封锁造成巨大供应缺口时，为什么附件数据中的油价没有冲到传统供需模型给出的 278-337 美元/桶，而是在 110-120 美元/桶附近形成平台。

当前最终主模型为“综合机制递推模型”：

- 短期窗口：RMSE 3.44 美元/桶，MAE 2.85 美元/桶，MAPE 2.86%。
- 基准对比：优于朴素上一日基准和滚动 ARIMA 基准。
- 长期情景：中性情景第 180 天约 98.61 美元/桶，悲观情景第 180 天约 114.49 美元/桶。
- 蒙特卡洛：外推期最高价突破 120 美元/桶概率约 8.0%，突破 130 美元/桶概率约 0.5%。
- 外部审计：EIA 官方周度数据、GPR 滞后审计、2017-2026 历史窗口检验均已接入论文。

## 文档入口

`docs/` 只保留 6 个入口文件，当前阅读入口固定如下：

| 文件 | 用途 |
|---|---|
| `docs/00_项目总览.md` | 项目是什么、做到哪一步、关键结论是什么 |
| `docs/01_建模方案.md` | 模型链路、因素纳入、短期/长期关系 |
| `docs/02_工程复现.md` | 环境、目录、运行命令 |
| `docs/03_交付物与数据索引.md` | 关键 CSV、图、报告、论文位置 |
| `docs/04_决策与质疑防御.md` | 建模决策和评委质疑防御 |
| `docs/05_历史决策与早期材料.md` | V1、旧状态、旧文档的单文件保留版 |

阶段运行报告统一保留在 `output/reports/`，它们是证据材料，不作为主阅读入口。

## 目录边界

| 目录 | 作用 |
