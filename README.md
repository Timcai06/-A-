# 数学建模 A 题：霍尔木兹海峡封锁对原油价格的影响

本项目用于完成浙江工商大学 2026 年大学生数学建模竞赛 A 题。当前主线已经收敛为一套可复算的综合机制递推模型，并生成最终论文 PDF/DOCX。根目录只保留入口文件、赛题原文、环境文件和目录导航；过程证据统一进入 `output/`、项目说明统一进入 `docs/`。

## 当前结论

本文解释的问题是：霍尔木兹封锁造成巨大供应缺口时，为什么附件数据中的油价没有冲到传统供需模型给出的 278-337 美元/桶，而是在 110-120 美元/桶附近形成平台。

当前最终主模型为“综合机制递推模型”：

- 短期窗口：RMSE 3.44 美元/桶，MAE 2.85 美元/桶，MAPE 2.86%。
- 基准对比：优于朴素上一日基准和滚动 ARIMA 基准。
- 长期情景：新版长期自适应反馈模型下，中性情景第 180 天约 92.43 美元/桶，悲观情景第 180 天约 106.83 美元/桶。
- 蒙特卡洛：第 180 天价格中位数约 92.85 美元/桶，外推期最高价突破 120 美元/桶的条件概率约 4.6%。
- 敏感性分析：已扩展为 14 个参数，新增长期机制透明层，覆盖制度风险占比、冲击不确定性占比、信心恢复底座和过剩供给回归强度。
- 统计审计：已加入 DM 检验、残差诊断和方向命中检验；R 版脚本作为可选复核入口。
- 外部审计：EIA 官方周度数据、GPR 滞后审计、2017-2026 历史窗口检验均已接入论文。

## 文档入口

`docs/` 只保留 6 个入口文件，当前阅读入口固定如下：

| 文件 | 用途 |
|---|---|
| `docs/00_项目总览.md` | 项目是什么、做到哪一步、关键结论是什么 |

## 目录边界

| 目录 | 作用 |
|---|---|
| `data/` | 原始附件、清洗数据、外部审计数据、参数来源 |
| `src/` | 数据清洗、建模、校准、分析、可视化代码 |
| `output/` | 模型结果、阶段报告、最终交付物 |
| `figures/` | 阶段图表和论文通用图 |
| `paper/` | 论文源码、参考文献和论文专用图 |
| `docs/` | 人读的项目关键信息 |
| `质疑报告/` | 外部评审、Gemini/专家质疑和防御矩阵 |
| `dashboard/` | 可选 Streamlit 展示系统 |
| `sql/` | PostgreSQL 草案，当前不是主线 |

根目录只保留最小入口和赛题原文 PDF；早期方案和旧文档内容已合并进 `docs/05_历史决策与早期材料.md`。

## 目录治理原则

- `paper/总论文.tex` 是唯一最终论文源文件。
- `output/final/` 只放最终 PDF/DOCX。
- `output/reports/` 只放阶段报告和模型证据。
- `docs/` 保持少量关键文档，不再扩散成报告仓库。
- `.cache/`、`tmp/`、`output/build/`、渲染检查图均为本机临时产物，不作为项目主线。
