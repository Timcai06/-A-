# 模型质量提升与技术实现计划

本文档用于承接 `审计报告/霍尔木兹封锁油价论文的深度文献审查与修订建议.docx` 的核心意见，并把后续工作从“继续润色论文”转成“用更硬的模型实验、数据约束和复现流程支撑论文结论”。

## 一、当前判断

项目目前已经完成了比较完整的数模主线：附件数据清洗、短期冲击模型、中长期油价调节模型、基准模型对比、敏感性分析、论文 PDF/DOCX 构建与图表体系。现在最值得继续提升的地方，不是再随意增加变量或堆一个更复杂的机器学习模型，而是把现有模型从“拟合效果不错”升级为：

- 能解释：价格变化可以拆成物理缺口、风险溢价、政策缓冲、预期修复等部分。
- 能验证：模型要打败朴素预测、ARIMA 等基准，并通过删块检验、事件窗口检验、参数稳定性检验。
- 能复现：每张图、每个指标、每组参数都能由脚本重新生成。
- 能外推：中长期油价调节模型不是主观画情景线，而是有状态转移逻辑和外生风险变量约束。
- 能答辩：面对“过拟合、内生性、样本短、长期预测过平”等质疑时，有明确的实验结果支撑。

## 二、核心目标

下一轮工作的核心目标是建立一个统一的“模型实验与质量审计系统”，让短期冲击模型和中长期油价调节模型都进入同一套评价框架。

```mermaid
flowchart LR
    A[附件数据与官方外生数据] --> B[特征与机制变量层]
    B --> C[短期冲击模型]
    B --> D[中长期油价调节模型]
    C --> E[基准模型对比]
    D --> E
    E --> F[质量审计与稳健性检验]
    F --> G[论文图表与结论更新]
```

这一轮不是为了把论文写得更“炫”，而是为了让论文里的每个核心结论都有代码、数据、检验结果和图表支撑。

## 四、技术实现路线

### 1. 建立模型实验管理层

计划新增或整理一套实验运行结构，用来统一管理模型、参数、指标和输出。

建议目录：

```text
src/
  experiments/
    registry.py          # 注册可比较的模型方案
    runner.py            # 统一运行实验
    metrics.py           # RMSE、MAE、MAPE、方向命中率等指标
    audit.py             # 质量门禁与稳健性检查
    leaderboard.py       # 输出模型对比排行榜

config/
  experiments/
    短期模型对比.yaml
    中长期油价调节模型对比.yaml

output/
  experiments/
    模型排行榜.csv
    短期模型质量审计.csv
    中长期油价调节模型质量审计.csv
```

这样做的意义是：以后不再靠人工记忆判断“哪个模型最好”，而是由统一实验表给出结论。

当前实现情况：项目已建立 `src/experiments/run_model_suite.py`，并输出 `output/experiments/模型实验总览.csv`、`output/experiments/短期模型指标排序.csv` 和 `output/experiments/长期情景概率摘要.csv`。后续若继续扩展，可再把实验注册和配置拆得更细，但现有版本已经足够支撑论文主线。

### 2. 短期冲击模型继续增强

短期冲击模型目前是项目最核心、最接近“最终结论”的部分，下一步继续补强它，但重点不是盲目压低误差，而是提升可信度。

重点任务：

- 增加事件窗口检验：观察封锁、升级、缓冲确认等关键日期前后，模型是否能解释价格跳变。
- 增加删块检验：分别删去前期冲击段、平台段、回落段，检查参数和结论是否稳定。
- 增加参数剖面图：观察关键参数变化时误差曲面是否平滑，避免“唯一神奇参数点”。
- 增加贡献分解：把预测价格拆成物理缺口、风险溢价、SPR/库存缓冲、绕道恢复、预期修复。
- 增加基准对比：继续保留朴素预测、ARIMA、Ridge 残差修正等模型，用来证明机制模型确实有价值。

当前实现情况：基准对比、删块检验、滞后平移、局部扰动、机制消融、拐点检验、统计审计、R 语言复核、Ridge 辅助层、参数剖面图和事件窗口检验表均已落地。最新增强质量门显示，“机制主模型 + 历史价格滞后特征阶段 Ridge”把 RMSE 从 3.380 降至 3.181，方向命中率从 66.7% 提升至 73.3%；高位平台形成段 RMSE 改善 7.79%，中期再定价回落段 RMSE 改善 11.47%。后续若继续补强，应优先做增强层的边界验证和输出口径统一，而不是盲目增加新参数。

主机制模型本身仍然可以继续优化，但优化边界要更严格。它承担的是“封锁冲击如何通过供需缺口、政策缓冲、风险溢价和预期修复形成价格平台”的解释任务，因此不能为了追求更低 RMSE 随意增加纯拟合项。下一步若继续动主机制模型，应优先选择下表中的方向：

| 优化方向 | 是否值得做 | 判断 |
|---|---|---|
| 参数校准权重重审 | 值得 | 可以检查是否过度照顾全局误差，而忽略高位平台和中期回落两个关键窗口。 |
| 机制贡献项边界收紧 | 值得 | 重点检查风险溢价、缓冲确认、预期修复三类项的量级是否符合题面和经济直觉。 |
| 事件段差异化参数 | 谨慎 | 可以允许冲击初期、平台期、回落期的少量结构差异，但必须预先定义窗口，不能事后随意切段。 |
| 引入更多外生风险变量 | 谨慎 | OVX/GPR 可作为风险状态或审计证据；短期拟合实验显示它们没有稳定超过价格滞后特征。 |
| 大幅增加自由参数 | 不建议 | 样本只有一个封锁事件窗口，参数过多会重新落入过拟合质疑。 |
| 用黑箱模型替代机制模型 | 不建议 | 纯 Ridge 已弱于机制模型；机器学习更适合作为辅助层，而不是主模型。 |

因此，短期主线的下一步不是简单问“还能不能把 RMSE 压低”，而是问：在不破坏题面机制和可解释性的前提下，主机制模型的每个贡献项是否还能校准得更稳、更有物理含义。最新主机制可优化性审计显示，围绕当前参数做单因子小扰动时，最好的扰动只把 RMSE 从 3.380 降到约 3.375，改善约 0.15%，不足以支撑替换主机制参数。若只是为了降低 0.1 左右的 RMSE 而增加难解释参数，收益不如保留当前主机制模型并使用阶段 Ridge 增强层。

当前主机制模型的更合理处理是：保留现有参数作为论文主机制解释版本；把 `output/reports/短期主机制模型可优化性审计报告.md` 作为内部证据，说明我们检查过主模型本体的局部可优化空间，但没有为了极小误差收益破坏机制解释。

在文献增强方向上，项目已额外建立 `src/analysis/short_term_literature_challenger.py`，把库存便利收益、SPR 可信度和非对称价格调整做成单独 Challenger。该候选不替换官方路径，只用于回答“按论文思路增强主机制结构是否值得”。当前结果显示，正则化选择的 Challenger 没有优于 Champion；仅按 RMSE 选择的 Challenger 也只改善约 0.13%。因此，短期主模型当前不应替换为文献增强版。更合理的处理是：把这些文献思想用于解释模型结构和长期风险变量选择，短期代码层面继续保留 Champion 主机制模型。

在增强层组合方向上，项目又建立 `src/analysis/short_term_hybrid_enhancement_search.py`，测试“阶段 Ridge + 只用过去误差的一阶在线反馈”。正则化最优候选仍然是不额外启用在线反馈；仅按 RMSE 选择时可把 RMSE 从 3.181 小幅压到约 3.175，但方向命中率从 73.33% 下降到 68.89%，最大绝对误差也略有上升。因此，当前最终增强层仍应保留为“机制主模型 + 阶段 Ridge”，不继续叠加在线反馈。

短期模型的质量评价不只看 RMSE，还要看：

| 评价维度 | 具体指标 | 作用 |
|---|---|---|
| 绝对误差 | RMSE、MAE | 看拟合精度 |
| 相对误差 | MAPE | 让评委理解误差比例 |
| 基准胜率 | 相对朴素预测、ARIMA 的改进率 | 证明模型不是复杂但无效 |
| 拐点表现 | 事件窗口局部误差、方向命中率 | 检查是否只是滞后跟随 |
| 参数稳定性 | 删块检验、扰动检验 | 防止过拟合 |
| 机制可信度 | 贡献分解是否符合经济逻辑 | 支撑论文解释 |

### 3. 中长期油价调节模型改成条件情景预测

中长期油价调节模型不应被包装成逐日精准预测。更合理的定位是：在封锁持续、缓冲消耗、风险衰减或升级等条件下，给出 60-180 天的价格区间和风险分布。

重点任务：

- 引入更明确的状态转移矩阵：缓和、维持、升级三类状态的基础概率要写清楚。
- 用 OVX、GPR 滞后项、期货期限结构等变量修正状态概率。
- 把绕道运输恢复改成容量受限的 S 型函数，而不是简单线性恢复。
- 把库存耗尽和二次跳涨风险放入尾部风险分析。
- 输出长期情景的区间预测，而不是只强调一条中性线。

当前实现情况：长期状态转移基础矩阵已经写入 `output/scenarios/长期状态转移基础矩阵.csv`，OVX/GPR 已用于状态转移压力，论文中已用蒙特卡洛情景树和状态转移扇形图替代单条中性线。下一步最值得补的是期货期限结构，因为它比新闻指数更接近真实市场定价。

中长期油价调节模型的合理定位：

```mermaid
flowchart TD
    A[短期冲击模型输出] --> B[封锁后价格平台与库存消耗状态]
    B --> C{中长期状态}
    C --> D[缓和: 风险衰减 供应恢复]
    C --> E[维持: 缓冲持续消耗]
    C --> F[升级: 二次冲击与风险重定价]
    D --> G[中长期价格区间]
    E --> G
    F --> G
```

### 4. 外生数据进入“约束层”，不是随意堆入主方程

已经引入或计划引入的外部数据，应当优先用于约束模型和解释风险状态，而不是直接替换附件真实价格。

变量使用原则：

| 数据类型 | 建议用途 | 注意事项 |
|---|---|---|
| EIA / IEA / OPEC 供需数据 | 约束全球供需缺口数量级 | 多为月频，不适合硬塞进日频拟合 |
| SPR 与商业库存 | 约束缓冲能力和库存消耗 | 不应写成无限释放 |
| GPR | 作为滞后风险状态或事件强度代理 | 避免同步解释当天价格 |
| OVX | 进入波动率、尾部风险、长期状态概率 | 不直接承担主价格方程全部解释 |
| 期货期限结构 | 刻画库存压力、便利收益和预防性需求 | 优先级较高 |
| 运费 / 保险费 | 刻画绕道运输和物流风险 | 数据获取难度较高，先作为增强项 |

当前实现情况：EIA、OPEC、JODI、GPR 和 OVX 已经进入约束或审计层。期货期限结构已建立 ICE 官方接入模板和公开证据记录，但尚未进入数值模型，原因是附件只有主力合约，不能直接计算 M1-M3 或 M1-M6 价差；后续需要获得 ICE 官方多期限 Brent 结算价，整理为可复现 CSV 后再进入中长期油价调节模型参数层。

### 5. 论文更新原则

论文后续不应继续无限加内容，而是用新的实验结果替换和强化已有结论。

更新顺序：

1. 先跑实验，得到模型排行榜和质量审计结果。
2. 再判断是否替换短期冲击模型或中长期油价调节模型。
3. 最后更新论文正文、表格、图表和附录。

论文中只保留最能支撑主线的图表。未进入论文的候选图，统一放在 `output/candidate_figures/`，不放入 `paper/figures/`。

## 六、验收标准

下一轮工作完成的标准不是“又写了多少页”，而是看以下问题是否能被明确回答：

- 短期冲击模型是否显著优于朴素预测和基础 ARIMA？
- 短期冲击模型是否存在明显滞后跟随？
- 参数扰动后，价格平台和核心结论是否仍然稳定？
- 中长期油价调节模型的状态转移概率是否有数据或规则来源？
- 中长期油价调节模型是否从单线条变成可信的区间和尾部风险解释？
- 外部数据是否只在合理位置发挥作用，没有造成内生性或口径混乱？
- 论文中的每张图和每张表是否都服务于一个核心结论？

当前验收判断：

长期状态转移模型已完成正式替换：当前主模型不再使用早期人工基础矩阵，而是优先读取 `output/scenarios/长期历史状态转移校准矩阵.csv` 中的“历史全样本矩阵”，并叠加温和 GPR/OVX 风险扰动。若历史校准矩阵不存在，代码会自动回退到原始人工矩阵，保证复现链条不断。

当前正式长期状态转移结果：

| 诊断项 | 替换前正式模型 | 替换后正式模型 | 判断 |
|---|---:|---:|---|
| 第180天 P50 | 87.92 | 91.21 | 中位数回到中性物理中心附近。 |
| 第180天 P95 | 93.70 | 98.29 | 上尾风险保留更充分。 |

| 突破130概率 | 3.4% | 5.7% | 极端尾部仍受控，没有失控放大。 |
| 第180天升级状态占比 | 2.7% | 5.7% | 后期升级状态保留有所增强。 |

这说明本轮替换达到了目标：长期模型不再只是一条过平的中性线，也没有把极端风险夸张成必然发生。正式主模型现在表达的是“中性中心回落、外推期仍有较高概率触及 120 美元平台、130 美元以上属于低概率尾部”。

## 八、我的执行理解

这轮工作的重点不是“再做一个模型”，而是把项目变成一个更专业的建模系统：  

用工程能力管理实验，用数据处理能力约束参数，用可视化能力发现模型问题，用论文写作把经过验证的结果表达出来。

最终目标是让评委看到：本文不是靠某一次漂亮拟合取胜，而是靠完整的证据链、稳健的实验设计和清晰的机制解释取胜。
