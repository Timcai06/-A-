# 执行计划与分工

## 1. 工作原则

本项目按“先跑通、再增强、最后论文精修”的顺序推进。所有重要结论都应能追溯到数据、脚本、CSV、图表或报告。

团队分工建议是：统计和建模同学负责理论合理性、公式推导和论文解释；计算机侧负责数据管道、模型实现、批量实验、可视化、复现和交付物工程化。
