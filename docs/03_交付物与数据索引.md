## 4. 图表材料

| 目录 | 用途 |
|---|---|
| `figures/` | 模型脚本生成区，保留过程图、备用图和通用分析图 |
| `paper/figures/` | 论文正式图片区，只存放总论文实际引用的中文图表 |

最终论文只从 `paper/figures/` 引用正式图。正式图要求文件名中文，图内标题、坐标轴、图例和注释也尽量中文化；RMSE、MAPE、P05-P95、GPR、LOESS 等必要缩写可以保留。

图表统一配色以 `config/figure_style.yml` 为准，当前主色系为 `#55ff37`、`#00e978`、`#00cfae`、`#00b3d9`、`#0095f2`、`#0074f2`。真实价格线保留深灰黑，亮绿色只作重点高亮或缓冲机制提示，避免整篇论文过度霓虹化。

R/ggplot2 学术增强图先由脚本生成到 `figures/`，最终构建时同步复制到 `paper/figures/`。当前正式使用 `R短期误差学术诊断.png`、`R长期状态转移扇形图.png` 和 `R历史基准误差分布图.png`。这些图不改变模型结果，只用于提升论文图表质感和统计表达。

蒙特卡洛图表当前采用两层表达：正文长期预测主图使用 `蒙特卡洛情景树高级组合图.png`，在一张图中合并路径云、扇形区间、第 180 天分布和突破概率曲线；敏感性分析中补充 `传统蒙特卡洛路径云图.png`，用于展示更传统的路径模拟证据。旧的 `蒙特卡洛价格扇形区间.png` 仍保留为备用图。

市场定价风险变量探索新增 `OVX隐含波动率滞后检验.png`，用于展示 Cboe/FRED OVX 隐含波动率在冲突窗口中的异常高位，以及价格与隐含波动率在 2026 年前后的同步压力。它目前是证据图和备选论文图，若后续写入正文，应同步复制到 `paper/figures/` 并在 `paper/figures_mapping.md` 中登记。

图表目录的权责划分如下：`figures/` 是脚本生成和通用图表区，`paper/figures/` 是论文编译引用区。若一张图已经进入正文，构建脚本会把 `figures/` 中的最新版同步到 `paper/figures/`，因此两处可能短暂存在同名同内容文件；这不是候选图混入论文，而是为了保证论文源码可以稳定编译。后续治理只删除 `paper/figures/` 中未被 LaTeX 或 `paper/figures_mapping.md` 引用的图片，不删除正式论文用图。

Mermaid 结构图源文件保存在 `paper/diagrams/`，构建脚本会渲染为 `paper/figures/短期冲击模型结构图.png` 和 `paper/figures/模型鲁棒性检验框架图.png`。这两张图只用于增强论文结构表达，不替代模型数据图。
