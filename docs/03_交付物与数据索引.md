## 4. 图表材料

| 目录 | 用途 |
|---|---|
| `figures/` | 模型脚本生成区，保留过程图、备用图和通用分析图 |
| `paper/figures/` | 论文正式图片区，只存放总论文实际引用的中文图表 |

最终论文只从 `paper/figures/` 引用正式图。正式图要求文件名中文，图内标题、坐标轴、图例和注释也尽量中文化；RMSE、MAPE、P05-P95、GPR、LOESS 等必要缩写可以保留。

R/ggplot2 学术增强图先由脚本生成到 `figures/`，最终构建时同步复制到 `paper/figures/`。当前正式使用 `R短期误差学术诊断.png`、`R长期状态转移扇形图.png` 和 `R历史基准误差分布图.png`。这些图不改变模型结果，只用于提升论文图表质感和统计表达。

Mermaid 结构图源文件保存在 `paper/diagrams/`，构建脚本会渲染为 `paper/figures/综合机制递推模型结构图.png` 和 `paper/figures/评审质疑防御框架图.png`。这两张图只用于增强论文结构表达，不替代模型数据图。
