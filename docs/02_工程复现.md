# 工程复现

## 1. 顶层目录边界

| 目录 | 角色 | 放什么 |
|---|---|---|
| `docs/` | 项目关键说明 | 总览、建模方案、工程复现、交付索引、决策防御、历史材料 |
| `docs/05_历史决策与早期材料.md` | 历史材料 | V1、旧状态、旧文档的单文件保留版 |
| `output/reports/` | 阶段运行报告 | 由脚本生成或支撑论文的结果报告 |
| `config/` | 配置中心 | 路径、参数、情景、校准范围 |
| `data/` | 数据源和数据说明 | 原始附件、清洗数据、数据字典、参数来源 |
| `src/` | 代码主线 | 清洗、建模、校准、分析、可视化 |
| `figures/` | 阶段图表 | 通用图表和模型图 |
| `paper/` | 论文工作区 | LaTeX 源码、参考文献、论文专用图 |
| `output/final/` | 当前交付物 | 总论文 PDF 和 DOCX |
| `dashboard/` | 可选展示 | Streamlit 展示台 |
| `scripts/` | 自动化脚本 | 环境约定、论文构建、R 审计和文档后处理 |
| `sql/` | 数据库设计 | PostgreSQL 草案，当前不是主线 |

## 2. 复现环境

推荐使用现有 conda/mamba 环境：

```bash
conda activate mathmodel-oil
source scripts/project_env.sh
```

当前主线不依赖 PostgreSQL。PostgreSQL 只作为后续结构化入库和展示扩展方案，不作为论文建模必要条件。

R 语言当前作为可选计量审计层，不作为主模型运行前提。当前机器已可以运行 R 审计脚本；Python 版本仍负责生成论文主线所需的统计审计结果，R 版用于复核核心结果，并补充 ADF、DM、Ljung-Box、ARCH、GARCH 和 Newey-West 稳健校准回归。C++ 暂不进入主线，除非后续需要大规模蒙特卡洛或真实多智能体仿真。

官方外生数据通过 `src.data.fetch_official_external_data` 单独更新。该脚本会联网抓取 EIA 官方周度序列和 JODI 官方多国月度 CSV，输出中文命名数据文件；因为它依赖外网和官方站点可用性，不放进每次论文构建的强制链路。

## 3. 常用命令

数据清洗：

```bash
python3 -m src.pipeline.clean_data
python3 -m src.pipeline.validate_data_cleaning --rerun
```

模型、校准与审计：

```bash
python3 -m src.models.baseline_supply_demand
python3 -m src.models.dynamic_short_term
python3 -m src.calibration.calibrate_dynamic_model
python3 -m src.analysis.short_term_model_defense
python3 -m src.analysis.short_term_model_quality
python3 -m src.analysis.short_term_model_fatal_challenges
python3 -m src.analysis.short_term_model_ablation
python3 -m src.scenarios.scenario_forecast
python3 -m src.analysis.sensitivity_analysis
python3 -m src.analysis.monte_carlo_scenario_tree
python3 -m src.analysis.lagged_risk_index_audit
python3 -m src.analysis.historical_robustness_audit
python3 -m src.analysis.statistical_audit
```

更新官方外生数据：

```bash
python3 -m src.data.fetch_official_external_data
```

可选 R 统计审计：

```bash
Rscript scripts/audit/statistical_audit.R
Rscript scripts/audit/r_econometric_audit.R
```

生成最终论文：

```bash
./scripts/build/build_final_paper.sh
```

输出：

- `output/final/A题_霍尔木兹海峡封锁对国际原油价格影响_论文.pdf`
- `output/final/A题_霍尔木兹海峡封锁对国际原油价格影响_论文.docx`

## 4. 当前代码结构治理

已完成：

- `src/common/paths.py`：统一项目根目录和输出目录创建。
- `src/common/metrics.py`：统一 RMSE、MAE、MAPE、方向命中率。
- `src/common/plotting.py`：统一 Matplotlib 中文图表风格。
- `src/calibration/` 已拆成设置、评估、参数空间、搜索、报告和入口模块。
- `src/scenarios/` 已拆成设置、参数构造、长期模拟、报告输出和入口模块。

仍需治理：

| 文件 | 当前问题 | 建议 |
|---|---|---|
| `src/models/dynamic_short_term.py` | 主模型、初筛、图表、报告在同一文件 | 后续把报告和初筛外移 |
| `src/analysis/short_term_model_defense.py` | 多种检验在一个文件 | 后续按检验类型拆分 |

治理原则：

- 保持原命令入口不变。
- 不改变输出文件名。
- 结构治理时不顺手改模型结论。
- 每轮治理后必须做编译和导入验证。
