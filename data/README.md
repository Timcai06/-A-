# data 目录说明

本目录保存真实数据、清洗数据、外部审计数据和参数来源说明。

## 子目录边界

| 目录 | 内容 |
|---|---|
| `raw/` | 附件原始价格数据，原则上不修改 |
| `processed/` | 清洗后的中文命名 CSV 和冲突窗口 CSV |
| `external/` | EIA、GPR 等外部官方/公开审计数据 |
| `metadata/` | 数据字典、参数来源和可信度说明 |
| `interim/` | 中间数据，非最终交付口径 |

## 数据口径

- 论文拟合目标只来自附件 CSV 的真实价格。
- 外部数据只用于长期数量级审计、风险高位审计和论文防御，不替代附件真实价格。
- 不使用爬虫数据编造未来价格。
