## 总评（一句话）

你们把**证据链、叙事纪律和防御性检验**做到了同类作品里相当高的水平；但若评委认真起来，火力会集中在：**短样本识别**、**统计显著性的脆弱**、**长期外推的可证伪性**、以及个别「检验看起来严、逻辑上却偏循环」的表述。论文不是输在「不够华丽」，而是输在**少数几处若被追问会出汗的缝隙**。

## 一、短期动态模型：最可能被「数学建模专家」穷追猛打

### 1.1 样本量与自由度：你们自己写了，但写得还不够「疼」

冲突窗口 **46 个交易日**，主模型却容纳多组物理/行为参数并经大规模随机搜索 + 差分进化 + 多轮精修。你们有过拟合压力测试与删块稳健性，这很好；但刁钻评委仍会问：

> 「有效自由度到底是多少？若把搜索空间体积也算进『隐式自由度』，你们报告的 RMSE 还有没有频率意义？」

**尖锐点：** 在 \(n=46\) 下，**3.44 美元/桶的 RMSE 本身并不能在经典渐近理论里自动转化为「显著好」**；它更多是**工程上好看**。你们对朴素基准的 DM 检验才是「向统计借一点合法性」——但见下节。

### 1.2 DM 与方向检验：显著，但显著得「刚好及格」

文中（及统计审计表）给出：平方损失 DM 单侧 **p≈0.023**，绝对损失 **p≈0.050** 贴边，方向命中相对 50% 单侧 **p≈0.048**。

**刁钻评语：**

- 这是**单一事先声明假设**下的 p 值吗？若评委认定你们「在多个基准、多种损失、多段 RMSE 里挑最漂亮的一个写进摘要」，**多重比较**会把这些 p 值整体打折扣；你们没有系统性的 Bonferroni / FDR 说明。  
- **p≈0.05 家族**在建模竞赛里属于「可发表边缘」，不是「铁证」。刁钻评委会说：换一周数据、换一个损失权重，优势可能消失——你们必须用**删块、时间轴、子区间**（你们已做一部分）把故事从「p 值」拉回「结构稳健」。

### 1.3 Newey–West 校准斜率：最容易被说成「自嗨检验」

表中写拟合值对真实价格回归，NW 斜率约 **1.046** 且高度显著。

**评委毒舌版：**

> 「你在同一串 \(P_t\) 上校准出 \(\hat P_t\)，再回归 \(\hat P_t\) 对 \(P_t\)，斜率接近 1 有什么信息量？这不近似于检验『拟合曲线像不像原曲线』吗？」

**辩护要点（你们需在口头答辩预备）：** 应明确这是**刻画性**诊断而非**因果识别**；或改为对**样本外**、**留块**、**纯基准**的同样回归作对照，强调「主结论不依赖这一条」。否则这一条在专家眼里是**减分项**：写进论文显得「计量堆砌」。

### 1.4 中期平台 RMSE 最高：与「平台解释」叙事存在张力

分段表写明 **中期平台 RMSE 4.39** 高于前期与后期。你们在统计审计里也诚实写了：相对朴素基准，中段改善率仅约 **3.9%**。

**刁钻追问：**

> 「既然赛题灵魂是解释 110–120 平台，为什么模型最难的正是中期？是不是说明：溢价/折价机制里仍有一块『用行为参数抹平』的成分，而不是完全被 SPR/库存/绕道识别出来？」

这不是否定全文，而是逼你们把**中段残余误差**与**机制边界**写得更谦卑——否则评委会说：「前期后期靠惯性 + 拐点拟合，中段靠调参。」

### 1.5 \(\phi=1\) 消融：有效，但略像「稻草人」

你们用 \(\phi=1\) 导致 RMSE 飙升来证明 \(\phi\) 不可省。刁钻评委会说：

> 「\(\phi=1\) 在经济学上本就粗暴，谁真会假设期货对剩余缺口**完全机械瞬时映射**？换一个更温和的伪反事实，比如只去掉折价项而保留 \(\phi\)，消融排序是否仍稳定？」

建议答辩时准备**多档消融阶梯**，避免给人「最极端反事实衬主结论」的印象。

### 1.6 供应中断取 1493 万桶/日量级：区间中「非端点」的最优

三情景表中断量有 1400 / **1493** / 1800。中性不是端点而是接近内点，**极易被问「是否用数据反推了中断量」**。

**辩护线：** 必须咬死：来自**题面范围 + 校准准则**下的中心设定，且敏感性/蒙特卡洛对 \(I\) 有联合扰动；否则评委一句「用价格拟合反推供给冲击」就够尴尬。

## 二、传统供需基准：逻辑你们圆回来了，仍可被「微观经济学考官」刁难

### 2.1 线性需求 vs 常弹性：你们现在写得比早期版本干净

第五节明确：主口径线性反事实**不是**常弹性 Taylor 近似，并给出常弹性机械上界作参照。这能挡掉一类公式质疑。

**仍可能被咬：** Brent 期货定价对象是**预期边际均衡 + 风险溢价**，不是「某条静态反需求曲线上的国内消费点」。用静态 \(D_0\) 与题面弹性去对标期货收盘价，**量级叙事成立，微观基础仍粗**。评委若懂油市会说：「你的 \(D_0\) 是全球还是 OECD？期货贴水期限结构呢？」——你们已在局限里承认未引入期限结构，答辩时要**主动收缩声称范围**：「本文是赛题约束下的机制量级反事实，不是 CME 微观结构模型。」

## 三、长期 60–180 天：华丽但「可证伪性」弱——专家火力最集中区

### 3.1 没有真值：所有曲线都是「条件故事」

你们文字上已反复强调**不是点预测**、是情景与尾部概率，这很专业。

**刁钻评委仍会说：**

> 「既然不可验证，为什么读者要相信第 180 天 93 或 108 这两个数字，而不是相信我也能写一套微分方程编出 95？」

**你们的防线**应是：**官方外生约束 + 敏感性排序 + MC 区间 + 状态树**四件套——这在竞赛里已经很强。但要预防评委说：

> 「EIA 是美国口径，JODI 是多国上报，凭什么约束霍尔木兹全球边际？」——你们文档里有边界说明，**口头答辩必须一句到位**，否则长期章会被打成「叙事通胀」。

### 3.2 蒙特卡洛与状态转移：联合分布是谁的「主观先验」？

文中给出 P05/P50/P95 与突破 120 的概率等。专家会问：

> 「参数联合分布的相关系数矩阵从哪里来？若只是独立扰动，真实危机中 SPR 弱与绕道弱往往**正相关**，独立抽样是否系统性低估/高估尾部？」

这是**建模选择问题**，没有标准答案；但若论文不写清「独立 vs 相关结构」，会被认为**尾部概率不可比**。

### 3.3 数字一致性：摘要/结论与 CSV 的细微出入

`output/monte_carlo/蒙特卡洛尾部风险摘要.csv` 显示突破 120 约为 **0.0915（9.15%）**，摘要写 **9.2%** 可视为四舍五入；P05/P95 与摘要中区间一致。若 README 等旧文档仍写 8.8%，属于**文档漂移**，评委若交叉材料会挑「到底信哪一个」。

## 四、结构、写作与「竞赛政治」：非数学但致命

1. **摘要信息密度过高**：数字、方法、检验、长期、GPR、历史窗口全挤进一页摘要。刁钻评委：「像技术报告目录，不像摘要。」可考虑**删去一个次要数字**换一句识别边界。  
2. **「优于 ARIMA」**：在 \(n=46\) 上 ARIMA 未必是强对手；专家会说：「赢了一个弱基准不值得大书特书。」更硬的是**经济解释检验**而非更多时间序列模型商标。  
3. **优点/局限性章节**：写得诚恳；但若局限性第三条与正文乐观语气在图表上「视觉冲突」，仍会被抓。
