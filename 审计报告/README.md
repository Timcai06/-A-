# 质疑报告目录

本目录用于保存“评委视角”和外部模型对当前论文、短期模型、长期情景模型的批判性审查材料。

## 文件说明

| 文件 | 用途 |
|---|---|
| `深度质疑与防守建议报告.md` | 外部深度质疑材料，偏“拆模型、找硬伤”。阅读时重点看它提出的问题，不直接照搬措辞进论文。 |
| `独立专家评审报告_20260512_模型诊断专家.md` | 新一轮独立专家诊断，重点质疑长期供需闭环、SPR 反馈、不确定性溢价和 `pressure_scale`。 |
| `优化评审报告_20260512.md` | 最新外部优化评审材料，用于继续检查论文表达、模型防御和目录治理后的主线一致性。 |
| `评委视角质疑与防御矩阵.md` | 当前项目的可执行防御清单，按质疑、真实性、已有证据、待补强动作、论文落点组织。后续改论文优先看这份。 |

## 使用方式

1. 先看 `评委视角质疑与防御矩阵.md`，确定下一轮论文和模型修改优先级。
2. 再回看 `深度质疑与防守建议报告.md`、`独立专家评审报告_20260512_模型诊断专家.md` 和 `优化评审报告_20260512.md`，检查有没有遗漏的尖锐问题。
3. 所有被采纳的修改，最终要落到 `paper/总论文.tex`、`output/reports/` 或 `docs/04_决策与质疑防御.md`，不能只停留在本目录。
