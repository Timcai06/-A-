# 审计报告目录

本目录用于保存“评委视角”和外部模型对当前论文、短期模型、长期情景模型的批判性审查材料。历史报告中可能保留旧路径表述；当前统一目录名为 `审计报告/`。

## 文件说明

| 文件 | 用途 |
|---|---|
| `cursor_A题论文刁钻专家评审审计_20260513.md` | Cursor 视角下的论文刁钻评审，用于检查论文逻辑和表达风险。 |
| `cursor_短期递推模型质量与改进审计_20260513.md` | Cursor 视角下的短期模型质量审计，用于短期模型后续补强。 |
| `deepseek_优化跟踪审计_20260512.md` | DeepSeek 对阶段性优化工作的跟踪审计。 |
| `deepseek_基准模型审计_20260513.md` | DeepSeek 对基准模型合理性和对比逻辑的审计。 |
| `deepseek_审计报告_20260512.md` | DeepSeek 对模型、论文和防御逻辑的综合审计。 |
| `deepseek_文件治理审计_20260513.md` | DeepSeek 对目录结构、重复文件和文档治理的审计。 |
| `deepseek_模型代码审计_20260512.md` | DeepSeek 对模型代码结构和潜在风险的审计。 |
| `霍尔木兹封锁油价论文的深度文献审查与修订建议.docx` | 论文文献审查与修订建议，作为后续模型质量提升计划的输入材料。 |

## 使用方式

1. 先看最新日期的审计报告，确定下一轮论文和模型修改优先级。
2. 再回看 DeepSeek、Cursor 等不同来源的报告，检查有没有重复出现的结构性问题。
3. 所有被采纳的修改，最终要落到 `paper/总论文.tex`、`output/reports/`、`src/` 或 `docs/04_决策与质疑防御.md`，不能只停留在本目录。
