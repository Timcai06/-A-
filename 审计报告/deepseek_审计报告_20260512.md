### 2.2 `pressure_scale`——论文最致命的结构性脆弱点

这是整篇论文**最危险的学术漏洞**。

**代码事实：**

```python
shortage_pressure = base_price * pressure_scale
                   * (residual_gap / base_demand)
                   / abs(elasticity)
```

其中 `pressure_scale = 0.0283`，`elasticity = -0.05`。

**数学实质：**

传统供需模型的价格传导：

$$\frac{\Delta P}{P} = \frac{\text{缺口比例}}{|\varepsilon|}$$

若缺口 15%、ε = -0.05，则 ΔP/P = 3.0，价格变为 4 倍（75 → 300 美元/桶）。

但在实际模型中：

$$\frac{\Delta P}{P} = 0.0283 \times \frac{\text{缺口比例}}{0.05} = 0.566 \times \text{缺口比例}$$

同样 15% 缺口下 ΔP/P = 0.085，价格仅涨 8.5%。

**等效弹性为 -0.05 / 0.0283 ≈ -1.77。** 这不是微调，这是将一个 -0.05 的极端低弹性变成了 -1.77 的中等弹性。

**叙事偏差：**

论文当前的叙事是："看，SPR + 库存 + 绕道 + 需求收缩成功把油价从 300 多压到 110 美元区间。"

更诚实的描述应为："价格平台的核心驱动力是市场对物理缺口的折价传导比例仅为 2.8%，各项缓冲机制在此基础上有边际贡献。"

**反驳性检验证据：**

| 检验 | pressure_scale | RMSE | 模拟峰值 |
|------|:---:|:---:|:---:|
| 0.5× | 0.01 | 3.50 | 110.42 |
| 当前值 | 0.03 | 3.44 | 110.42 |
| 1.5× | 0.04 | 3.47 | 110.42 |
| 2.0× | 0.06 | 3.64 | 110.46 |
| **1.0 绝对值压力传导** | **1.00** | **26.55** | **166.84** |

当 `pressure_scale = 1.0`（即真正使用题面弹性）时，RMSE 从 3.44 飙升至 26.55，模拟峰值升至 166.84。说明如果市场真的按 -0.05 弹性定价，任何 SPR+库存+绕道组合都无法把价格压在 110 美元。

**建议修复方案：**

1. 论文中必须正面论述：`pressure_scale` 的语义是"期货市场对剩余物理缺口的折价传导比例"，不是需求价格弹性。题面弹性仍严格用于传统供需反事实上界。
2. 增加文献支撑：引用 Kilian (2009) 关于期货市场预期定价的论述，或 Hamilton (2009) 关于石油市场投机缓冲的讨论，解释为什么期货市场不会机械地把物理缺口按低弹性直接映射为价格。
3. 参数分类要更透明：在论文参数表中将 `pressure_scale` 明确标注为"行为校准参数 / 价格传导系数"，并列出其最敏感的 0.5×-2.0× 扰动范围。

### 2.3 自由度问题

21 个连续校准参数 vs 46 个交易日，自由度比约 2.2。这在数学建模竞赛中属于**偏紧但可辩护**的范围，前提是：

- 物理层参数（供应中断、SPR 上限、库存量、绕道上限等）来自题面或外部数据，不是自由参数。
- 真正自由的行为参数是 `pressure_scale`、`risk_weight`、`uncertainty_floor`、`inventory_response`、`adjustment_speed` 和几个折价/修复参数，约 10 个。
- 多目标校准函数中的权重（0.20、0.35 等）本身也是隐藏超参数。

当前论文对此已有参数分类意识，但建议在正文中更明确地画一条线：哪些参数来自题面（不可调）、哪些来自外部审计（不可调）、哪些来自校准（可调但接受敏感性检验）。

### 3.2 仍然存在的长期模型风险

**风险一：供需闭环仍未完全闭合。**

当中性第 180 天出现 50 万桶/日过剩且价格仍为 92.43 美元/桶（战前 75 美元）时，模型依赖过剩供给折价项（仅 0.06 美元/桶）来提供向下的压力。但 50 万桶/日的过剩在长期应该产生更强的价格回归动力。当前过剩折价强度偏弱——这是一个应该主动承认的模型局限，而不是隐藏它。

**风险二：制度风险溢价的长期稳态缺乏外部校准。**

当前 `regime_risk_premium` 在 t→∞ 时趋近于约 3.7 美元/桶。这个"永久制度风险底座"是否有文献或历史先例支撑？论文需要做到：要么提供外部依据（如 1990 年海湾战争后风险溢价的持续时间），要么明确标注为"缺乏外部校准的专家判断参数"。

**风险三：蒙特卡洛联合分布来自模型内生设定。**

论文对此已有清醒表述（"条件概率而非真实市场概率"），但建议把这句话从附录提到正文长期结果部分，让评委一眼看到这份清醒。

### 3.3 长期模型的正确定位

长期模型不应被评判为"预测是否准确"（因为没有未来真实值），而应被评判为：

- **机制一致性**：供需变化 → 价格变化的方向和量级是否合理
- **参数边界**：每个长期参数的取值是否有题面或文献依据
- **尾部风险识别**：模型是否识别出了真正危险的情景组合

### 4.2 需要改进的叙事问题

**问题一：论文读起来仍像工程报告而非竞赛论文。**

部分章节流露出"我们做了阶段 1、阶段 2、阶段 3..."的流水账感。建议在最终精修中把所有"阶段"语言去掉，改成围绕核心矛盾的论证推进："为什么传统模型高估 → 哪些机制压低了价格 → 这些机制的贡献各是多少 → 持续封锁下哪里最危险"。

**问题二：`pressure_scale` 在正文中的论述过于含蓄。**

这是论文最容易被攻击的数学漏洞，应该在模型公式部分用一段话正面解释：它的经济含义是什么、为什么不能等于 1.0、有哪些文献支撑、如果扰动它会怎样。

**问题三：长期结果的主图应该是蒙特卡洛扇形图而非三条中心线。**

三条中心线容易被误读为"预测"，扇形区间才传达了不确定性。建议将 `monte_carlo_price_fan.png` 提升为长期模型的第一张图。

## 七、最终结论

这是一份**在数学建模竞赛标准下具备较强竞争力**的论文。它的核心优势不在于某一个模型特别精巧，而在于形成了一个完整的证据链条：

```
传统供需基准 → 证明"为什么需要解释"
    ↓
综合机制递推模型 → 给出"解释是什么"
    ↓
多维度防御检验 → 证明"解释不是凑出来的"
    ↓
情景预测 + 敏感性 + 蒙特卡洛 → 回答"持续封锁下哪里最危险"
    ↓
外部审计（GPR + EIA + 历史窗口） → 提供"解释有事实支撑"
```

当前最需要加固的薄弱点只有两个：

- **`pressure_scale` 的学术合法性论述**——评委最可能抓住的数学漏洞
- **长期供需闭环中过剩价格回归的强度**——经济学逻辑的收尾

把这两个问题处理到位，这篇论文在答辩中就有了比较完整的防御纵深。
