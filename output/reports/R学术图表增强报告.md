# R学术图表增强报告

## 定位

本脚本使用 R + ggplot2 对论文关键图进行学术化重绘，不改变 Python 主模型、参数校准或预测结果。它的价值是提升论文图表统一性、可读性和统计表达质感。

## 新增图表

- `figures/R短期误差学术诊断.png`：用残差柱形和 LOESS 趋势展示短期模型误差结构。
- `figures/R长期状态转移扇形图.png`：用双层置信带展示长期状态转移区间，弱化单条中性线的误读。
- `figures/R历史基准误差分布图.png`：用分位带展示冲突窗口相对历史同长度窗口的预测难度。
- `figures/R参数敏感性龙卷风图.png`：用横向排序图突出长期模型的关键敏感变量。
- `figures/R候选模型误差对比.png`：用分组柱形图展示短期候选模型的误差权衡。
- `figures/R市场风险变量滞后检验.png`：用标准化时间序列展示 OVX 等市场风险变量的滞后证据。

## 关键数值

- 短期模型 RMSE 为 3.42，朴素基准 RMSE 为 4.52，改善率为 24.38%。
- 状态转移第 180 天 P05-P95 为 90.20-108.95 美元/桶。
- 朴素上一日基准在冲突窗口的历史分位数约为 98.5%。

## 论文使用建议

R 图表适合放在模型检验、长期预测和历史稳健性部分。它们不宣称模型更准，但能把“为什么可信、为什么不应只看一条线”的证据讲得更清楚。
