# 期货期限结构数据接入报告

## 核心结论

期限结构是长期模型下一步最值得补的市场定价变量。它比新闻情绪更接近交易层面的库存压力、近端短缺和远期风险预期；但它必须来自可复现的多期限官方结算价，不能用附件主力合约或网页截图反推出一条曲线。

当前未发现 `data/external/futures/布伦特期货多期限结算价_手工官方.csv`，也未通过 Nasdaq Data Link API 拉取到 CHRIS 连续期限合约。因此本轮没有生成可用于入模的连续 M1-M3、M1-M6 数值输入，也没有把期限结构写入长期模型参数。

## 数据源判断

| 数据对象 | 推荐来源 | URL | 当前状态 | 是否入模 |
|---|---|---|---|---|
| Brent多期限官方结算价 | ICE End of Day / ICE Report Center | https://www.ice.com/report/83 | 作为首选来源；完整历史多期限结算价通常需要网页交互或授权下载 | 尚未入模，等待可复现CSV |
| Brent连续期限结算价 | Nasdaq Data Link CHRIS/ICE_B1, ICE_B3, ICE_B6 | https://data.nasdaq.com/data/CHRIS | 已建立可选API入口；需要 NASDAQ_DATA_LINK_API_KEY 环境变量 | 若成功拉取，可作为可复现连续期限结构代理；需在论文中说明它是连续合约代理而非逐个实际交割月合约 |
| EIA期限结构公开证据 | EIA Today in Energy | https://www.eia.gov/todayinenergy/detail.php?id=67544 | 记录Dated Brent相对front-month futures的公开描述 | 仅作论文外部证据，不作为连续数值输入 |

## 后续接入规则

若获得 ICE 或其他可复现来源的 Brent 多期限结算价，应整理为：

`data/external/futures/布伦特期货多期限结算价_手工官方.csv`

字段必须包括：

| 字段 | 含义 |
|---|---|
| `trade_date` | 交易日期 |
| `contract_code` | 合约代码或合约名 |
| `contract_month` | 交割月份，格式如 `2026-06` |
| `settlement_price` | 官方结算价，美元/桶 |
| `source_name` | 来源名称 |
| `source_url` | 来源链接 |

脚本会自动生成：

- `data/external/futures/布伦特期货多期限结算价_标准化.csv`
- `data/external/futures/布伦特连续期限结算价_Nasdaq_CHRIS.csv`
- `output/risk/布伦特期货期限结构_日度指标.csv`
- `data/external/futures/期货期限结构来源表.csv`
- `data/external/futures/期限结构公开证据表.csv`
- `data/external/futures/Nasdaq_CHRIS拉取状态.csv`

## 建模使用边界

- 有完整多期限数据前，期限结构只作为外部证据和下一步计划，不进入模型参数。
- 有 ICE 实际交割月数据后，优先使用 M1-M3、M1-M6 价差和曲线斜率约束长期状态转移概率，不直接替代附件真实价格。
- 若使用 Nasdaq CHRIS 连续期限合约，应写成“连续期限结构代理”，不能声称它等同于逐个实际交割月官方曲线。
- 若曲线处于强 backwardation，可提高“近端短缺/升级”概率；若曲线转为 contango，可提高“缓和/库存修复”概率。
