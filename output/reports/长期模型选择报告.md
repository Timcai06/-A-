# 长期主模型选型与当前口径说明

## 1. 目的

本报告说明项目为什么采用“自适应反馈三情景 + 蒙特卡洛情景树 + 状态转移扰动”的长期模型组合作为论文主线。旧长期外推虽然能给出趋势，但容易被评委理解成几条过于光滑的线；当前版本把长期预测改为“中心路径 + 历史波动校准的不确定性区间 + 尾部风险概率”，更符合本题的冲击预测属性。

## 2. 选型标准

| 标准 | 含义 |
|---|---|
| 供需闭环 | 缺口闭合后，SPR 不能机械满额释放，供给过剩要能拉低价格 |
| 风险溢价可解释 | 前期冲击不确定性可衰减，长期制度风险应随未解决物理压力下降 |
| 尾部风险保留 | 中性路径可以回归，但悲观和蒙特卡洛尾部仍要保留二次跳涨风险 |
| 历史尺度校准 | 2017-2025 历史同长度窗口用于校准长期扰动和跳变强度 |
| 论文防御性 | 能回应“长期直线化”“常数托底”“预测区间缺失”等质疑 |

## 3. 当前主模型结果

| 指标 | 当前结果 | 解释 |
|---|---:|---|
| 乐观情景第 180 天价格 | 87.39 | 缓冲生效后价格充分回归 |
| 中性情景第 180 天价格 | 93.38 | 作为中心路径，不解释为逐日精确预测 |
| 悲观情景第 180 天价格 | 108.82 | 供应恢复慢、制度风险残留时仍保留高位压力 |
| 悲观情景外推期最高价 | 131.70 | 二次跳涨风险仍存在 |
| 蒙特卡洛第 180 天 P05-P95 | 88.71--104.53 | 历史波动与 OPEC 全球基线校准后的条件预测区间 |
| 蒙特卡洛第 180 天 P50 | 95.05 | 与中性情景中心路径基本一致 |
| 外推期最高价突破 120 概率 | 10.8% | 尾部风险下降但未消失 |
| 外推期最高价突破 130 概率 | 1.1% | 极端上行属于小概率压力情景 |
| 状态转移第 180 天 P05-P95 | 85.98--94.84 | 缓和、维持、升级三状态扰动下的条件区间 |
| 状态转移外推期最高价 P95 | 127.03 | 说明长期仍有阶段性冲高风险 |

## 4. 最终选择

论文主线保留一个长期模型框架：以三情景路径回答任务二的“未来 60-180 天走势”，以蒙特卡洛和状态转移模型补足不确定性、尾部风险和非平滑路径。旧模型不再作为论文候选模型展示，只保留在历史审计和 Git 历史中。

## 5. 对论文表述的影响

论文统一采用当前口径：

- 中性情景第 180 天约 93.38 美元/桶；
- 悲观情景第 180 天约 108.82 美元/桶；
- 蒙特卡洛第 180 天 5%-95% 区间为 88.71--104.53 美元/桶；
- 外推期最高价突破 120 美元/桶的条件概率约为 10.8%；
- 状态转移扰动显示第 180 天 5%-95% 区间为 85.98--94.84 美元/桶，外推期最高价 P95 约 127.03 美元/桶。

这套表述把长期模型从“单线预测”升级为“条件预测 + 风险区间 + 尾部概率”，比单纯追求一条好看的中性曲线更稳。
