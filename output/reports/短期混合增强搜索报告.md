# 短期混合增强搜索报告

> 本报告只探索模型优化方式，不替换官方主机制模型，也不写入论文正文。

## 核心结论

混合增强没有超过阶段 Ridge，当前阶段 Ridge 仍是短期增强层的更稳选择。

本轮测试的是“阶段 Ridge + 只用过去误差的一阶在线反馈”。最佳候选使用 `enhanced_short_term_price` 作为基准路径，shrinkage=0.0，单日校正上限=1.0。它相对机制主模型的 RMSE 改善为 5.87%，相对阶段 Ridge 的 RMSE 改善为 0.00%。

如果完全按 RMSE 而不看正则化得分，最小 RMSE 候选为 3.175，相对阶段 Ridge 只改善 0.20%，但方向命中率从 73.33% 降到 68.89%，最大绝对误差也从 5.816 上升到 5.968。因此它不适合作为最终增强模型。

## 建模判断

1. 阶段 Ridge 是离线增强层，只用冲突前历史价格特征训练，适合作为最终增强候选。
2. 在线反馈层需要每天拿到上一日真实价格后才能更新，适合“滚动修正”，不适合作为纯事前静态预测。
3. 如果混合增强只小幅优于阶段 Ridge，论文里不应把它作为主结论；可以作为技术储备或附加审计。
4. 下一步真正可能提升质量的是：把增强层做更严格的滚动留后验证，而不是继续叠加更多修正项。
