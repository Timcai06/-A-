# 短期模型质量复盘与提升方向

## 结论

当前短期动态模型已经从“可用于论文主体分析”提升到“优秀短期模型”水平：它不是单纯追求曲线贴合，而是把供应中断、SPR 释放、绕道能力、需求弹性、恐慌溢价、库存缓冲、缓冲确认折价和预期修复折价放进了同一个可解释框架中。

本轮提质后，模型已经解决了原先后期再定价和低价回落解释偏弱的问题。综合最优 RMSE 从 7.05 降至 3.50，后期再定价 RMSE 从 9.18 降至 2.99，低价回落 RMSE 从 9.15 降至 3.51。

## 参考优秀数学建模作品的质量标准

结合公开竞赛章程、评阅要点和 MCM/ICM Outstanding 论文特征，一个质量合格甚至优秀的模型通常不只是“拟合曲线好看”，而是要同时满足以下要求：

| 评价维度 | 合格要求 | 优秀要求 | 对本项目的含义 |
|---|---|---|---|
| 问题针对性 | 模型直接回答赛题问题 | 模型结构和赛题机制高度绑定 | 不能只做时间序列预测，要解释“封锁如何影响油价” |
| 假设合理性 | 假设不违背题面和常识 | 每个关键假设都能解释其经济含义 | 供应中断、SPR、绕道、需求弹性必须有合理范围 |
| 数据处理 | 数据来源清楚、处理可复现 | 异常、窗口、口径都有解释 | 附件数据已清洗，冲突窗口与全历史数据已区分 |
| 模型解释力 | 能给出主要结果 | 能解释为什么出现峰值、平台、回落 | 当前已能解释峰值、平台和回落 |
| 数值效果 | 有 RMSE、MAE 等误差指标 | 有分段误差、峰值误差、稳健性比较 | 阶段 4 已具备多目标、分段误差和局部精修 |
| 稳健性 | 参数变化后结论不崩 | 多候选、多情景、敏感性分析支撑结论 | 阶段 5、6 还需要继续补强 |
| 可复现性 | 能复现结果图表 | 数据、代码、图表、报告一键串联 | 当前项目骨架已经具备可复现基础 |
| 论文表达 | 结构完整、图表清楚 | 摘要、模型、结果、检验形成闭环 | 后续需要把代码结果转成论文语言 |

## 当前拟合效果判断

阶段 4 综合最优模型的核心结果如下：

| 指标 | 当前结果 | 判断 |
|---|---:|---|
| 全窗口 RMSE | 3.50 | 优秀，可以支撑短期动态解释 |
| 全窗口 MAE | 2.91 | 优秀，平均误差控制较好 |
| 峰值误差 | -3.75 | 峰值略低估，但在可接受范围内 |
| 末日误差 | 0.00 | 末端价格贴合很好 |
| 前期冲击 RMSE | 3.15 | 良好 |
| 中期平台 RMSE | 4.36 | 良好 |
| 后期再定价 RMSE | 2.99 | 优秀 |
| 高价平台 RMSE | 2.74 | 优秀 |
| 低价回落 RMSE | 3.51 | 良好到优秀 |

所以一句话判断：模型现在已经不是“勉强能解释”，而是可以在论文里作为主模型使用的优秀短期模型。它既能解释“短期冲击后为什么进入高价平台”，也能解释“缓冲机制生效后为什么出现阶段性回落”。

## 为什么不能只看 RMSE

本题不是普通预测题，而是机制解释题。单纯把 RMSE 压低，可能会得到一条看起来更贴近的曲线，但牺牲了峰值、平台和经济解释。

阶段 4 已经保留了三类候选：

| 候选类型 | 优点 | 缺点 | 用途 |
|---|---|---|---|
| 综合最优 | 整体、峰值、平台、末端和分段误差都较均衡 | 峰值仍略低估 | 作为主模型 |
| RMSE 最优 | 与综合最优一致 | 峰值仍略低估 | 用作主模型和对照模型 |
| 平台解释最优 | 对高价平台解释最好 | 整体误差偏大 | 用作机制讨论 |

这个设计比只拿一个最小 RMSE 模型更像竞赛论文里的优秀做法，因为它能主动说明“我们如何权衡拟合和解释”。

## 短期模型还能怎么提高

本轮已经把模型从“一个统一动态过程”升级为更接近分阶段解释的动态过程：

| 改进方向 | 具体做法 | 预期提升 |
|---|---|---|
| 分阶段机制 | 划分前期冲击、中期平台、后期再定价 | 已降低分段误差 |
| 缓冲确认折价 | 缺口被 SPR、库存、绕道压住后出现第一轮降温 | 改善 3 月下旬偏高问题 |
| 预期修复因子 | 加入市场预期修复导致的阶段性再定价折价 | 解释 4 月中后期价格回落 |
| 不确定性溢价动态化 | 让 uncertainty_premium 不再长期维持高位 | 减少模型后期偏高 |
| 分段目标函数 | 前期、中期、后期、高价平台、低价回落均纳入目标函数 | 避免只优化整体 RMSE |
| 连续局部精修 | 在随机搜索后使用 differential evolution 精修参数 | 把 RMSE 从 4.84 进一步降到 3.50 |
| 参数稳健性 | 对关键参数做扰动和置信区间 | 增强论文可信度 |
| 消融实验 | 分别去掉 SPR、绕道、恐慌、库存模块 | 证明每个机制不是装饰项 |
| 多情景预测 | 乐观、中性、悲观三种封锁持续路径 | 支撑阶段 5 预测任务 |

## 后续建议

阶段 5 现在可以建立在这一版优秀短期模型之上。后续不建议再过度追求附件窗口内的点对点拟合，而应把重点转向：

1. 用当前综合最优参数作为中性情景基准；
2. 设计乐观、中性、悲观三套封锁持续路径；
3. 做参数敏感性和消融实验，证明结论不是由单个参数强行调出来的。

这样模型会更像一篇完整数学建模论文，而不是一个只拟合附件数据的程序。
