# output 目录说明

本目录保存模型运行结果、阶段报告和最终交付物。它是“机器生成证据区”，不是项目说明文档区。

## 子目录边界

| 目录 | 内容 |
|---|---|
| `final/` | 最终交付 PDF 和 DOCX，只应放正式交付物 |
| `reports/` | 阶段报告、审计报告、质疑回应报告 |
| `baseline/` | 传统供需基准模型结果 |
| `calibration/` | 短期动态模型校准、误差、消融和稳健性结果 |
| `scenarios/` | 60--180 天三情景长期预测结果 |
| `sensitivity/` | 单因素敏感性分析结果 |
| `monte_carlo/` | 蒙特卡洛情景树结果 |
| `risk/` | GPR 滞后风险指数审计结果 |
| `history/` | 2017--2026 历史窗口稳健性检验 |
| `statistics/` | 短期模型统计审计、R 计量审计、残差诊断和 DM 检验 |
| `qa/` | 小型 CSV 审计证据；渲染截图和临时检查图不进入 Git |
| `build/` | LaTeX/Pandoc 构建临时目录，不进入 Git |

## 使用原则

- 写论文时优先查 `output/reports/` 和各结果 CSV。
- 交付时只引用 `output/final/`。
- 不要把人工说明文档放进 `output/`，应放入 `docs/` 或 `审计报告/`。
